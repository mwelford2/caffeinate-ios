# Changelog

## 1.0.1 — 2026-09-01

App icon and source icon now match the in-app button — grey coffee cup on a light grey circle.


## 1.0.0 — 2026-09-01

First release.

- One-button keep-awake (`isIdleTimerDisabled`), state persisted across launches
- Optional "dim screen while awake" setting
- Shortcuts / Siri actions: Keep Device Awake, Allow Device to Sleep,
  Toggle Keep Device Awake, Is Device Being Kept Awake
- Universal (iPhone + iPad), iOS 17+
